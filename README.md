A tiny self-contained Python program that writes one short, warm family
scene — a grandchild teaching Grandpa to use a phone — to the entry file.

## The scene

> Grandpa held the phone like it might bite. "Tap the green one, Grandpa," I said.
> He tapped — and my face filled the screen. "There you are," he smiled. "Now I can carry you in my pocket."

Two characters, a small reversal (a phone that feels threatening becomes a
pocket full of family), spoken lines, and a last line that reframes the first.

## Run

```sh
python3 main.py
```

Writes to `/output/entry.txt` by default; set `ENTRY_OUTPUT` to override the
path. No network, no external files, no dependencies.
